Dev-C++ 编译运行速查卡

针对本机实测环境：Dev-C++ 5.11 · TDM-GCC 4.9.2 (64-bit) · 英文界面

这张卡的来源 下面的快捷键不是网上的二手说法，是从本机 Dev-C++ 自带的帮助文件 Dev-C++ 自带帮助 Help\Subjects\Compiling.htm 里的默认值。 你随时可以自己打开那个文件核对。

键盘

  • Ctrl+N — 新建源文件
  • Ctrl+O — 打开文件
  • Ctrl+S — 保存
  • F9 — 编译（只编译，不运行）
  • F10 — 运行（运行上次编译出的 .exe）
  • F11 — 编译并运行（最常用）
  • F12 — 全部重建（改了 .h 文件后用）

界面语言改成中文

当前界面是英文。要改：Tools → Environment Options → General， 把 Language 改成 Chinese.lng。
建议先别改——英文界面下搜报错信息更容易搜到答案。

新建文件的正确流程

  1. File → New → Source File
  2. 敲代码
  3. File → Save As，后缀写 .cpp
  4. F11

最小可用程序骨架

#include <iostream>

int main() {
    std::cout << "内容" << std::endl;
    return 0;
}

四段结构各自在干嘛

  • #include <iostream> — 借输入输出工具箱
  • int main() — 程序入口，从这里开始跑
  • std::cout << ... — 把内容送到屏幕上
  • return 0; — 报告正常结束

报错速查

cout was not declared 漏了 #include <iostream> 或 std::
end1 was not declared endl 的字母 l 打成数字 1
_main 找不到 int main() 漏写或拼错
cannot open output file 上次的黑窗口还开着，关掉再编译
中文变乱码 编码问题，先只用英文输出

本机环境事实（省得以后再查一遍）

IDE本机安装的 Dev-C++
真正的编译器MinGW64\bin\g++.exe（示例环境 TDM-GCC 4.9.2，64 位）
Dev-C++ 自带帮助Help\index.htm
个人设置文件%APPDATA%\Dev-Cpp\devcpp.ini
防止窗口闪退的组件Dev-C++ 自带的 ConsolePauser.exe
默认语言标准gnu++98 —— 4.9.2 的默认值，不是 C++11
两个别做的动作
  • 不要加 system("pause"); —— Dev-C++ 自带 ConsolePauser，不需要它。
  • 不要把源文件保存成 .c —— 那样 Dev-C++ 会按 C 语言编译，你的 C++ 代码会报一堆错。
